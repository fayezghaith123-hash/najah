# نظام الحضور الذكي — جامعة النجاح

## التشغيل على جهازك
1. ثبّت Node.js 20 أو أحدث.
2. `npm install`
3. `cp .env.example .env` (يكفي كما هو للتجربة).
4. `npm start` ثم افتح http://localhost:3000/login
5. اضغط "تفعيل الحساب لأول مرة"، اكتب البريد المسموح، وسيُطبع رمز التفعيل في الطرفية (لأنه لا يوجد بريد مضبوط). اكتب الرمز وكلمة مرور جديدة.

ملاحظة: الطلاب يفتحون الرابط الموجود داخل QR، لذا للتجربة بالهاتف ضع في `BASE_URL` عنوان جهازك على الشبكة (مثل http://192.168.1.5:3000).

## هيكل المشروع
- `server.js` نقطة البداية · `db.js` قاعدة البيانات · `bootstrap.js` الحسابات والمادة · `mailer.js` البريد
- `routes/` واجهات الخادم · `public/` الصفحات · `public/js/` سكربتات الصفحات
